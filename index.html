Autre méthode (PC) : copier la session depuis la console
  1. Ouvre une fenêtre de navigation privée, va sur aevyz.com et connecte-toi avec Discord.
  2. Ouvre la console (F12). Colle ceci, puis appuie sur Entrée. Si le navigateur bloque le collage, tape d'abord allow pasting.
    copy(localStorage.getItem('sb-vmobbiulvvchbezkxeat-auth-token'))
  3. Ferme la fenêtre privée sans te déconnecter : se déconnecter annulerait la session.
  4. Colle le contenu ici. Il donne accès à ton compte : ne le colle nulle part ailleurs.
